# 🛒 BazarDor (বাজার দর)

### Daily Market Price Tracker for Bangladesh

**BazarDor** is a modern and responsive web application that helps users explore daily market prices of essential commodities in Bangladesh. Users can view product prices, track price increases and decreases, browse product categories, and manage their profiles through a user-friendly interface.

## ✨ Key Features

1. **Daily Market Prices** — View the latest available prices of essential commodities in Bangladesh.

2. **Price Increase and Decrease Tracking** — Explore products whose prices have increased or decreased, helping users understand market trends.

3. **Product Categories** — Browse products by category for easy navigation and a better shopping experience.

4. **User Authentication** — Sign up, sign in, and securely manage user sessions using Better Auth.

5. **Profile Management** — View account information, update profile details, and sign out of your account.

## 🛠️ Technologies Used

- **Next.js** — React framework for building the web application.
- **React** — Library for building interactive user interfaces.
- **JavaScript (JSX)** — Application logic and reusable components.
- **Tailwind CSS** — Utility-first CSS framework for responsive styling.
- **DaisyUI** — Component library for building UI elements.
- **Better Auth** — Authentication and session management.
- **MongoDB** — Database for authentication-related data.
- **REST API** — Fetching product and category information.

## 📱 Responsive Design

BazarDor is designed to provide a smooth user experience across mobile phones, tablets, laptops, and desktop devices.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd bazar-dor
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory and add the required environment variables for the API and authentication configuration.

### 5. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The goal of BazarDor is to make daily market price information more accessible and help users stay informed about changes in the prices of essential commodities.
